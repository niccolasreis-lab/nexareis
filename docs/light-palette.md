# Paleta clara

Pedido: preservar o site aprovado e manter apenas a paleta clara. Layout, conteúdo, imagens, destinos, contratos e animações existentes continuam iguais.

| Uso | Cor |
| --- | --- |
| Fundo | `#F5F5F2` |
| Superfície | `#FFFFFF` |
| Texto principal | `#152329` |
| Texto secundário | `#52616B` |
| Ciano legível | `#005F73` |
| Azul institucional | `#0055CC` |

Cabeçalho, menu móvel, painéis ilustrativos, páginas de serviços e projetos, orçamento e métricas usam superfícies claras. A preferência escura do sistema não troca o tema. Texto, seleção, foco, cursor e controles nativos acompanham a paleta.

O perfil pessoal preserva creme, verde e amarelo; os painéis de contato e competências passam a verde claro, e o rodapé usa creme. O currículo A4 e as capturas reais dos projetos permanecem com suas cores originais.

A verificação reutiliza os testes existentes de navegação, formulário, movimento reduzido, contraste e layouts de 320 a 1440 px. Nenhum teste automatizado envia notificações reais.

A revisão complementar apontou a tipografia e a grade decorativa já existentes. Foram preservadas porque o pedido altera somente as cores. Não houve substituição de fontes, conteúdo ou composição.
